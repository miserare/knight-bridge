Help & privacy

Chess.com: after a game ends, choose Load PGN or FEN from this tab, or use Share Game → PGN. Export the full game even if the replay cursor is earlier.

Lichess: signed-in transfers submit the normal import form with computer analysis selected. If signed out, sign in and use Continue here. If limited, leave the imported game open and try Lichess’s own control later.

A FEN opens a position, with no historical mistakes report. Never reconstruct missing castling rights or earlier moves.

Installation: load the unpacked Chrome/Edge build, or temporarily load the Firefox manifest through about:debugging. Permanent Firefox installation requires Mozilla signing.

Independent extension; not endorsed by Chess.com or Lichess. Imports are public. Clearing local data does not delete games already sent to Lichess.
